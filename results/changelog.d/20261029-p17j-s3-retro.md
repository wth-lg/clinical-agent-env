The row then has no label and `audit-check` counts the PASS. `pass` is accepted only when all of these hold (outcomes.ts passConfirmationBreaks; verifier-phase-P17i-P17j-S3retro-1 A1): the current grade is PASS; the row needs adjudication, because model_fault is unclear, llm_auditor_agrees is false, or an adjudicated yes overrules an auditor no; and, when the row's own label is grader or environment, a non-empty note says why it is overruled. On a PASS row, a clinically_acceptable no is answered by the label grader with evidence (GR5). An audit outcome GRADER_BUG on a PASS is an outcome mismatch, and the message now names the GR5 form.
